# Portfolio — Jasmin Steinbrecher

Personal portfolio website for an aerospace engineer, built with plain HTML, CSS, and JavaScript.

## Deployment (GitHub Pages)

1. Push this repository to GitHub:
   ```
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/<username>/<repo>.git
   git push -u origin main
   ```

2. Go to **Settings &rarr; Pages** in your GitHub repository.

3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.

4. Your site will be live at `https://<username>.github.io/<repo>/`.

   > If your repo is named `<username>.github.io`, the site will be at `https://<username>.github.io/`.

## Customization

- **Profile photo:** Replace `assets/profile.jpg` with your own image (square works best).
- **Resume:** Replace `assets/resume.pdf` with your actual resume PDF.
- **Content:** Edit the HTML files to add your real papers, projects, bio, and contact details.

## Features

- Dark / light mode toggle (persisted in localStorage)
- Responsive layout (desktop & mobile)
- Academic publications section
- Practical projects section
- Resume download link
- Contact page with email, LinkedIn, GitHub
